# 📊 Antigravity Token 统计与多维度可视化分析器

一个专为 **Google Antigravity**（Antigravity IDE 与 Antigravity CLI）打造的高性能、多维度 Token 消耗统计、分析与可视化报告生成工具。

支持从本地会话数据库中提取全量模型调用元数据，提供包括模型维度、时间趋势、会话排行、提示词细分、运行环境分布及交互式 HTML 仪表盘在内的全方位数据洞察。

---

## ✨ 核心特性

- 🖥️ **跨环境自动发现与自适应扫描**
  - **Windows 本地**：智能自适应寻找当前用户及系统所有用户目录下的 `.gemini` 和 `.antigravity` 目录，彻底兼容各类机型与用户名；
  - **WSL2 跨环境**：自动探测已安装的 WSL2 发行版（如 Ubuntu、Debian 等），无缝遍历 `/root` 与 `/home/*` 下的所有会话数据库；
  - **解决 UNC 网络锁**：采用 `immutable=1` 只读不可变模式，彻底规避跨 9P/virtio-fs 共享文件系统的 SQLite 文件锁冲突与阻塞。

- 🚀 **工具类型自动识别与顶层切换**
  - 精准区分 **Antigravity IDE** 与 **Antigravity CLI** 会话；
  - 仪表盘顶层提供工具切换胶囊，全页面各指标卡片、图表与数据表格支持 0 毫秒联动切换。

- 🎨 **高级视觉与双主题无缝切换**
  - **☀️ 暖阳米黄（默认）**：舒缓柔和的羊皮纸浅米色调（`#fcf8f0`）搭配高雅卡片排版与暖琥珀金主色，防视觉疲劳；
  - **🌙 极客暗黑（可选）**：深邃 Slate 暗蓝灰（`#0b1120`）极客风格搭配科技冰蓝高亮；
  - 记忆用户偏好（`localStorage`），坐标轴与网格线平滑自适应换色。

- 🔥 **GitHub 风格年度贡献热力图 (Heatmap)**
  - 经典 52/53 周矩阵布局，自适应双主题 5 级色阶渲染；
  - 支持年份切换筛选（如 `2026年`）；
  - 鼠标悬停实时浮动显示当日日期、总消耗 Token 及调用轮次。

- 📈 **紧凑走势图与实时求和统计卡片栏**
  - 柱状图高度精心压缩至约 70%，视野紧凑精致；
  - **日期范围筛选**：快捷胶囊（7天、14天、近30天、60天、90天、全部） + 精准起止日期控件；
  - **模型列表下拉多选**：带独立复选框，支持全选/清空与组合筛选；
  - **实时求和统计卡片栏**：根据选定日期区间与模型，实时动态重新计算总消耗、未缓存输入、缓存读取（及命中率）、模型生成输出（及思考 Token 占比）、调用轮次及日均值。

- 🌐 **一键运行自动打开报表**
  - 程序跑完后，自动调用系统默认浏览器弹出新标签页打开交互式仪表盘，无需手动翻找文件路径。

## 🚀 快速开始

### 1. 环境准备
- Python 3.8+ (推荐 Python 3.12)
- 无需安装重量级第三方 Web 框架，依赖极简轻量。

### 2. 执行统计与报告导出
在项目根目录下直接运行：

```bash
python export_report.py
```

执行后将自动完成以下流程：
1. 自适应发现 Windows 本地与 WSL2 环境下的所有 `conversations/*.db` 数据库；
2. 提取并全局去重解析所有模型调用的元数据；
3. 输出控制台概览摘要；
4. 导出全量结构化 Markdown 报告（`Antigravity_Token_Report.md`）；
5. 导出交互式可视化仪表盘（`Antigravity_Token_Dashboard.html`）；
6. 自动启动系统默认浏览器呈现仪表盘。
